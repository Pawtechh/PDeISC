# Mobile — Surf Rental Mar del Plata

Aplicación móvil construida con React Native, Expo SDK 52+, Redux Toolkit y React Navigation.

## Scripts (próximos pasos en MP1)
- `npx expo start`: Inicia el bundler de Metro
- `npx expo run:android`: Compila e inicia la app en emulador o dispositivo Android
- `npx expo run:ios`: Compila e inicia en simulador iOS
- `npm run test`: Ejecuta pruebas con Jest y React Native Testing Library
